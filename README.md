# 🧠 DevOps Quiz App
---
---

🔗 Live Demo: https://gkmfrombs.github.io/devOps-prctice/

A lightweight, mobile-friendly quiz app to practice **Linux & DevOps interview questions**.

---

## ✨ Features

- 📱 Responsive design (works on mobile)
- 🎯 200+ questions (JSON-based)
- ⏱️ Timer per question
- 🎨 Instant feedback  
  - 🟢 Correct  
  - 🔴 Wrong + correct answer shown
- 🔁 Previous / Next navigation
- 📊 Score tracking
- 🎚️ Difficulty filter

---

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript (Vanilla)
- GitHub Pages

---
